## Что подтверждено

- Названия i-SENSYS и imageRUNNER взяты из [европейского портала руководств Canon](https://oip.manual.canon/portal-eu-af-me-ru/).
- Старые CAPT-модели дополнены из [официального перечня Linux CAPT 2.71](https://my.canon/en/support/0100459601).
- В `catalog/drivers/canon.json` записаны официальные пакеты [Linux UFR II/UFRII LT 6.40](https://sg.canon/en/support/0100924010), [Windows Generic Plus UFR II 3.50](https://my.canon/en/support/0101310501) и Linux CAPT 2.71 с исходными списками моделей Canon.
- У 250 карточек найден кандидат по одному или нескольким спискам драйверов.

## Что ещё нужно проверить

Все `files` пока пусты. Установщики и PPD не загружены в Releases, не извлечены и не протестированы на принтерах.

`targetOperatingSystems` указывает **желаемый охват**: Windows 10 x64, Windows 11 x64 и Linux x86_64. Это не обещание поддержки каждой ОС для каждой старой модели. Отсутствие кандидата также не означает отсутствие драйвера: нужны другие модельные или архивные пакеты Canon.

В `driverCandidates`:

- `vendor-listed` — модель найдена по названию в официальном перечне соответствующего пакета; фактическая печать и конкретная версия Linux всё равно не проверены.
- `regional-name-match-needs-review` — европейское i-SENSYS и региональное imageCLASS/LASER SHOT совпали по коду модели. Это **кандидат для ручной проверки**, не автоматическое утверждение совместимости.

Дата выпуска устройства и признак «снят с производства» не выводятся из возраста драйвера.

## Размещение файлов

Для пакетов Canon установлен режим `official-download-only`: панель может направлять на официальный источник. Условия страницы загрузки ограничивают повторное распространение. Наличие GPL-компонентов не означает автоматического разрешения перепубликовать полный пакет Canon или все его PPD. Для зеркала в Releases нужны подходящие условия конкретного компонента или отдельное разрешение.

Linux PPD сам по себе может требовать фильтры Canon и другие компоненты. Старые CAPT-принтеры нельзя автоматически заменять драйвером UFR II.

## Повторяемость импорта

`scripts/import-canon.mjs <папка-с-HTML>` читает заранее скачанные официальные страницы и добавляет только отсутствующие карточки. HTML не исполняется. Существующие карточки и их проверенные файлы не перезаписываются. Для обновления источников сначала проверить изменения Canon и даты, затем отдельно проверить новые карточки.

Входные файлы: `isensys-{lbp,mf}-{bw,cl}.html`, `{ir,iradv,iradvdx}-{bw,cl}.html` с портала Canon и `ufr-linux.html`, `ufr-windows.html`, `capt-linux.html` со страниц пакетов. Исходные HTML и установщики в Git не включаются.
