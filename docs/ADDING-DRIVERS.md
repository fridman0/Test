# Как добавить драйвер

1. Проверить модель, поддерживаемые ОС и архитектуры, источник файла и право на распространение.
2. Подготовить понятное имя файла: `производитель-модель-ос-архитектура-версия.расширение`. Использовать латинские буквы, цифры, дефисы и точки.
3. В GitHub открыть **Releases → Draft a new release**. Создать уникальный тег модели и версии. Загрузить установщики и готовые PPD во вложения, описать совместимость и опубликовать релиз. Использовать окончательный релиз, а не draft или prerelease.
4. Получить прямую ссылку вида `https://github.com/fridman0/Test/releases/download/ТЕГ/ИМЯ-ФАЙЛА`. Проверить скачивание в отдельном окне браузера.
5. Вычислить размер в байтах и SHA-256 оригинального файла. На Windows: `Get-FileHash -Algorithm SHA256 -LiteralPath 'путь-к-файлу'`; размер — свойство `Length` файла. Не придумывать значения и не использовать MD5 вместо SHA-256.
6. Добавить производителя в `catalog/manufacturers.json`: объект с полями `id` (стабильное имя латиницей) и `name` (отображаемое название). Не дублировать существующий идентификатор.
7. Создать `catalog/printers/идентификатор-производителя/идентификатор-модели.json` по схеме `schemas/printer.schema.json`.
8. Добавить относительный путь `printers/производитель/модель.json` в массив `printers` файла `catalog/index.json`.
9. Выполнить `node scripts/validate-catalog.mjs` и опубликовать изменения каталога после успешной проверки.

## Поля карточки модели

| Поле | Содержание |
| --- | --- |
| `id` | Уникальный идентификатор модели: латинские строчные буквы, цифры, дефисы |
| `manufacturer` | Идентификатор из manufacturers.json |
| `model` | Полное название модели |
| `files` | Список проверенных вариантов драйверов и PPD |

## Поля каждого файла

| Поле | Содержание |
| --- | --- |
| `id` | Уникальный внутри модели идентификатор файла |
| `kind` | `driver` или `ppd` |
| `os` | `windows`, `linux` или `macos` |
| `osVersions` | Непустой список явно проверенных версий ОС/дистрибутивов |
| `architecture` | `x86`, `x86_64`, `arm64` или `any`; `any` только при подтверждённой независимости от архитектуры |
| `version` | Версия драйвера или PPD |
| `filename` | Точное имя вложения в Releases |
| `sizeBytes` | Положительное целое число байтов |
| `sha256` | 64 шестнадцатеричных символа, нижний регистр |
| `downloadUrl` | Прямая HTTPS-ссылка на вложение релиза fridman0/Test |
| `sourceUrl` | HTTPS-ссылка на официальный источник или исходники сборщика |
| `license` | Название лицензии или сведения о разрешении распространять файл |

Одна карточка может содержать несколько ОС, архитектур и версий. Не указывать поддержку всех ОС без проверки. Наличие драйвера Windows не означает совместимость его PPD с Linux.

## Обновление и удаление

Новую версию публиковать в новом релизе и добавлять или заменять запись в каталоге. Старые релизы сохранять для воспроизводимости. При обнаружении повреждённого или неподходящего файла сначала убрать его из каталога, затем исправлять публикацию. Git-проверка не скачивает установщики и не подтверждает безопасность или фактическую совместимость файлов.
