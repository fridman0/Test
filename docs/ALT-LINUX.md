# Canon: файлы и ALT Linux

Целевая Linux-система проекта — ALT Linux. Версия и архитектура пока не уточнены. Ни один пакет пока не прошёл установку и пробную печать в ALT.

В catalog/drivers/canon.json находятся 8 официальных пакетов Canon: ссылки производителя, прямые ссылки загрузки, размер, SHA-256 и заявленные производителем ОС. Полные установщики не зеркалируются без разрешения на распространение.

В релизе https://github.com/fridman0/Test/releases/tag/canon-ppd-2026-10-22 опубликованы 1079 исходных PPD с GPL-2.0-or-later в общем архиве, лицензия и манифест контрольных сумм. Для 60 карточек есть отдельные PPD с совпадением обозначения модели. Это не означает готовность всех 436 принтеров: для остальных требуется подбор и проверка. Состояние каждого принтера указано в catalog/coverage/canon.json.

PPD описывает возможности принтера, но требует установленного CUPS и фильтра Canon, указанного в files[].requires. Пакеты RPM производителя не считаются автоматически совместимыми с ALT. Нельзя обходить зависимости установкой с --nodeps. Сначала нужно определить версию ALT, архитектуру, доступность зависимостей и подходящего пакета; затем выполнить пробную печать.

В files[].osVersions пустой список означает отсутствие подтверждённых версий дистрибутива. verification=extracted-not-print-tested означает извлечение оригинального файла и проверку его происхождения/контрольной суммы, а не испытание печати. status=ready означает наличие файла для скачивания, а не подтверждение Windows и ALT одновременно.

Обозначения i-SENSYS / imageCLASS и названия семейств требуют отдельной проверки. Кандидат драйвера не означает подтверждённую совместимость. Windows 10/11 проверяются отдельно по официальному списку модели и пакета.

Официальная документация ALT по настройке печати: https://docs.altlinux.org/ru-RU/alt-workstation/10.4/html/alt-workstation/ch42.html
