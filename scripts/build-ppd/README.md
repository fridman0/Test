# Сборщики PPD

Здесь будут исходники рецептов сборки для конкретных моделей. Готовые PPD публикуются в Releases и описываются в каталоге.

Рецепт должен перечислять поддерживаемые модели, зависимости, исходный драйвер и его контрольную сумму, версию рецепта, команды проверки результата. Запрещено подставлять пользовательский ввод в команды оболочки.

Автоматическая сборка пока не настроена. Создание PPD не заменяет необходимые фильтры и драйверы печати: их наличие и совместимость нужно проверять отдельно.
