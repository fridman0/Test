# PrintHub — каталог драйверов

Публичный источник файлов для панели PrintHub. Установщики и готовые PPD хранятся во вложениях GitHub Releases, а в истории Git — только каталог, документация и исходники сборщиков.

## Структура

```text
catalog/
  index.json                 # список файлов карточек моделей
  manufacturers.json         # производители и их стабильные идентификаторы
  printers/                  # карточки моделей по папкам производителей
schemas/printer.schema.json  # формат карточки
scripts/validate-catalog.mjs # проверка каталога без установки зависимостей
scripts/build-ppd/           # будущие сборщики PPD
docs/ADDING-DRIVERS.md        # порядок добавления файлов
```

В каталог добавлены 436 карточек Canon из официальных источников: i-SENSYS LBP/MF, imageRUNNER, imageRUNNER ADVANCE/DX и старые LBP/CAPT. См. [охват и состояние проверки Canon](docs/CANON.md).

Карточка со статусом `awaiting-files` описывает модель, но ещё не содержит готовых файлов. `targetOperatingSystems` — план подбора драйверов, не подтверждение совместимости. Отсутствие PPD не означает, что его можно автоматически создать для любого принтера.

## Проверка

Нужен Node.js 22 или новее:

```sh
node scripts/validate-catalog.mjs
```

## Основные правила

- Не загружать EXE, MSI, DEB, RPM, архивы и готовые PPD в историю Git: использовать Releases.
- На одну версию файлов одной модели — отдельный релиз, например `hp-laserjet-pro-m404dn-2026.10.1`. Не заменять уже опубликованные файлы; выпускать новую версию.
- Для каждого файла указывать ОС, версию ОС, архитектуру, версию драйвера, размер в байтах и SHA-256.
- В каталог включать только проверенные файлы, которые разрешено распространять. Хранить ссылку на источник и сведения о лицензии.
- Репозиторий публичный: опубликованные файлы доступны также без входа в панель. Пароли, ключи, персональные данные и токены здесь не хранятся.

Подробная инструкция: [добавление драйверов](docs/ADDING-DRIVERS.md).
