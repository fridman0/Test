# PrintHub на Cloudflare Workers

Панель с входом по логину и паролю, управлением пользователями и выпадающими списками принтеров. Драйверы и PPD остаются в GitHub Releases.

## Первый запуск

1. Создайте бесплатный аккаунт Cloudflare и подтвердите почту. Платный тариф включать не требуется.
2. В Workers & Pages подключите GitHub-репозиторий fridman0/Test. Корневая папка проекта: panel. Команда сборки: npm run build. Команда публикации: npm run deploy.
3. Создайте D1-базу printhub. Замените нулевой database_id в panel/wrangler.json её настоящим ID. Привязка должна называться DB.
4. Перед первой публикацией примените миграции: npx wrangler d1 migrations apply printhub --remote. В дальнейшем запускайте при изменении схемы. Существующую базу не удалять.
5. В настройках Worker добавьте два секрета: PASSWORD_PEPPER и SETUP_TOKEN, каждый — случайная строка минимум 32 байта. Не добавляйте значения в GitHub. В командной строке можно использовать npx wrangler secret put PASSWORD_PEPPER и npx wrangler secret put SETUP_TOKEN (значения вводятся скрыто). Для проверки сборки эти секреты не требуются.
6. На HTTPS-странице Worker создайте первого администратора top_s.nordflex24: введите ключ SETUP_TOKEN и новый пароль минимум из 14 символов. После создания удалите секрет SETUP_TOKEN. PASSWORD_PEPPER сохраняйте неизменным: его потеря сделает существующие пароли недействительными.

Пароли, токены, D1-выгрузки и сессии в этот репозиторий не включены. Старые пользователи и пароли автоматически не перенесены. Новый адрес станет известен после публикации в вашем аккаунте. Старый сайт сохраняется до проверки нового.

## Проверка

npm ci
npm test
npm run build

Проверки включают запрет создания администратора без ключа и с поддельным заголовком владельца, вход, cookie, защиту запросов, роли, блокировку и отзыв сессий.

После публикации необходимо проверить вход в реальном Worker на бесплатном тарифе и пробное скачивание PPD. До этого перенос не считается завершённым.
